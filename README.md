# 基于图书馆用户行为的智能推荐系统

## 项目简介

这是一个基于用户行为分析的图书馆智能推荐系统，运用机器学习算法为用户提供个性化的图书推荐服务。系统集成了多种推荐算法，包括协同过滤、内容过滤和混合推荐，能够深度分析用户的阅读行为模式，提供精准的推荐结果。

## 核心功能

### 🎯 智能推荐算法
- **协同过滤推荐**: 基于用户相似度和物品相似度的推荐
- **内容过滤推荐**: 基于图书内容特征的推荐
- **流行度推荐**: 基于图书受欢迎程度的推荐
- **混合推荐**: 综合多种算法的加权推荐

### 📊 用户行为分析
- **阅读统计**: 评分数量、借阅数量、平均评分等
- **偏好分析**: 类别偏好、作者偏好、兴趣匹配度
- **活动模式**: 月度活动分析、借阅频率统计
- **行为特征**: 评分倾向、借阅习惯、归还及时性

### 🖥️ 现代化界面
- **响应式设计**: 支持PC端和移动端访问
- **直观交互**: 简洁美观的用户界面
- **实时反馈**: 即时的操作反馈和数据更新
- **可视化展示**: 丰富的图表和统计信息

### 🔧 系统管理
- **用户管理**: 用户档案维护和行为跟踪
- **图书管理**: 图书信息管理和库存控制
- **评分系统**: 用户评分收集和统计分析
- **借阅管理**: 借阅记录管理和状态跟踪

### 推荐算法
- **用户协同过滤**: UserKNN
- **物品协同过滤**: ItemKNN
- **矩阵分解**: SVD降维
- **内容过滤**: TF-IDF + 余弦相似度
- **混合推荐**: 加权融合算法

## 使用指南

### 基本操作流程

1. **选择用户**: 从用户列表中选择要分析的用户
2. **获取推荐**: 选择推荐算法并获取个性化推荐
3. **行为分析**: 查看用户的详细行为分析报告
4. **互动操作**: 为图书评分或进行借阅操作

### 推荐算法说明

#### 混合推荐（推荐）
- 综合多种算法的优势
- 权重配置: 协同过滤(40%) + 内容过滤(40%) + 流行度(20%)
- 适用于大多数推荐场景

#### 协同过滤
- 基于用户行为相似度
- 适合有丰富历史数据的用户
- "喜欢这本书的用户还喜欢..."

#### 内容过滤
- 基于图书内容特征
- 适合新用户或特定兴趣用户
- "因为您读过XX类书籍..."

#### 流行度推荐
- 基于图书整体受欢迎程度
- 适合冷启动场景
- "热门推荐"

## API接口

### 用户相关
- `GET /api/users` - 获取所有用户
- `GET /api/user/{user_id}/behavior` - 获取用户行为分析
- `POST /api/user/{user_id}/rate_book` - 用户评分图书
- `POST /api/user/{user_id}/borrow_book` - 用户借阅图书

### 推荐相关
- `GET /api/user/{user_id}/recommendations` - 获取用户推荐
  - 参数: `method` (推荐算法), `num` (推荐数量)

### 图书相关
- `GET /api/books` - 获取所有图书

### 统计相关
- `GET /api/stats` - 获取系统统计信息
